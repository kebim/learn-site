Shell scripting basics

A shell script is a text file of commands. Automating repeated tasks is the heart of Linux administration.

#!/usr/bin/env bash
set -euo pipefail          # stop on errors and unset variables

backup_dir="/var/backups/site"
mkdir -p "$backup_dir"

for f in /etc/nginx/*.conf; do
  if [ -r "$f" ]; then
    cp "$f" "$backup_dir/$(basename "$f").$(date +%F)"
    echo "saved $f"
  fi
done

Building blocks

Variables are set as name="value" and read as $name. Tests use [ -f file ] or [ "$a" = "$b" ]. Loops are for and while. Every command returns an exit code: 0 means success, anything else is a failure, and $? holds the last one.

Good habits

Quote your variables, start with set -euo pipefail, test on a copy of your data, and run chmod +x script.sh before executing it with ./script.sh.
