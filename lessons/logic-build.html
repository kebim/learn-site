Designing and testing a circuit

Every digital design follows the same loop: describe the behaviour, write the truth table, derive an expression, draw the gates, then test every input combination. You can practise the whole loop in the circuit builder on the tech site.

Step 1: Describe and tabulate

Take a half adder, which adds two single bits. It needs two outputs: a sum bit S and a carry bit C.

Step 2: Find the expressions

The sum is 1 when the inputs differ, so S = A XOR B. The carry is 1 only when both inputs are 1, so C = A AND B.

Step 3: Build it

  1. Open the Build yourself tool and press Clear board.
  2. Add two Switches, one XOR gate, one AND gate and two Lamps.
  3. Drag a wire from each switch's output dot to an input pin on both gates.
  4. Connect the XOR output to one lamp (S) and the AND output to the other (C).

Step 4: Test every row

Set the switches to all four combinations and compare the builder's truth table with yours. A circuit can match three rows and still fail the fourth, so never test just one case.

Debugging checklist

An unconnected input pin counts as 0, so a lamp that never lights often means a missing wire. Each input pin accepts only one wire. If a wire loops back to an earlier gate you have created feedback, and the circuit now has memory, as in the SR latch example.

Practice

2. An alarm sounds when the door is open and the system is armed, or when the panic button is pressed. Write the expression and count the truth table rows.

Show answer
