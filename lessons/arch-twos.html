Number systems and two's complement

Computers store integers as fixed-width bit patterns, so the width decides what values fit.

Unsigned

N bits represent 0 to 2N - 1. With 8 bits that is 0 to 255.

Two's complement

For signed numbers the top bit has a negative weight of -2N-1. The range is -2N-1 to 2N-1 - 1, so 8 bits cover -128 to 127. To negate a number, invert every bit and add 1.

+18 = 00010010
invert 11101101
add 1  11101110   = -18  (hex EE)

Why it won

Addition works identically for signed and unsigned values, and there is only one zero, so the same adder circuit serves both.

Overflow

In 8 bits, 127 + 1 gives 10000000, which reads as -128. Overflow happens when two operands of the same sign give a result of the opposite sign.
