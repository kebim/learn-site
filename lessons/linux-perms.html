Users and permissions

Each file has an owner, a group, and three permission sets: user, group, other. Each set is read (4), write (2), execute (1).

ls -l notes.sh
-rwxr-x--- 1 ana dev 120 notes.sh

chmod 750 notes.sh      # rwx r-x ---
chown ana:dev notes.sh
sudo useradd -m -G dev sam

750 means the owner has 4+2+1=7, the group has 4+1=5, and others have 0. Use the chmod calculator on the tech site to check your numbers.

Default permissions: umask

New files start from 666 and new directories from 777, minus the umask. With the common umask 022, files become 644 and directories 755.

Special bits

setuid (4000) runs a program as its owner, which is how passwd can edit protected files. sticky (1000) on a shared directory such as /tmp lets users delete only their own files. Setgid (2000) on a directory makes new files inherit its group.

Common mistakes

Using chmod 777 to "fix" an error hides the real problem and lets anyone modify the file. Find out which user runs the service with ps aux, then give that user the minimum access it needs.
