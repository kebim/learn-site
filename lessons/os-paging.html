Paging and virtual memory

Virtual memory gives each process its own private address space. Memory is cut into fixed-size pages (commonly 4 KB) that the OS maps to physical frames using a page table.

Address translation

A virtual address is a page number plus an offset. With 4 KB pages the offset is 12 bits. Take address 0x3A7C: page 3, offset 0xA7C. If the page table maps page 3 to frame 9, the physical address is 9 x 4096 + 0xA7C = 0x9A7C.

Page faults

If a page's valid bit is 0, the CPU raises a page fault. The OS loads the page from disk, updates the table and restarts the instruction.

The TLB

The translation lookaside buffer caches recent translations. A hit costs about one cycle; a miss means walking the page table in memory.

Replacement example

FIFO with 3 frames and references 1 2 3 4 1 2: pages 1, 2 and 3 fault while filling the frames, 4 evicts 1, then 1 evicts 2, then 2 evicts 3. All 6 references fault.
