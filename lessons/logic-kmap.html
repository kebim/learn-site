Karnaugh maps

A Karnaugh map (K-map) is a grid that lays out a truth table so neighbouring cells differ by exactly one variable. Grouping adjacent 1s simplifies a Boolean function without algebra.

Rules

  1. Label rows and columns in Gray code (00, 01, 11, 10), not binary order.
  2. Group 1s in rectangles of size 1, 2, 4, 8 or 16.
  3. Groups may wrap around the edges, so the map is really a torus.
  4. Make groups as large as possible, and use as few groups as possible.
  5. Cells may be in more than one group. "Don't care" cells (X) may be used if they enlarge a group.

Worked example

F(A,B,C) = Σm(0,1,2,5,6,7). Map (rows A, columns BC in Gray order 00, 01, 11, 10):

ABC00011110
01101
10111

Groups: m0 and m1 give ¬A·¬B. m1 and m5 give ¬B·C. m5 and m7 give A·C. m6 and m7 give A·B. m0 and m2 give ¬A·¬C, and m2 and m6 give B·¬C. A minimal cover is F = ¬A·¬B + B·¬C + A·C.

Check your own functions with the K-map tool on the tech site. K-maps are practical up to 4 variables; beyond that, use the Quine-McCluskey method, which the tool uses internally.
