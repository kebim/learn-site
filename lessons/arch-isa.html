Instruction sets

The ISA is the contract between software and hardware. x86-64 is CISC (many complex instructions); ARM and RISC-V are RISC (few simple ones).

; RISC-V: c = a + b
lw  t0, 0(a0)
lw  t1, 4(a0)
add t2, t0, t1
sw  t2, 8(a0)
