Registers and counters

Flip-flops chained together become the registers and counters that give every CPU its memory and timing.

Shift register

D flip-flops in a row, each output feeding the next input. On every clock edge the stored bits move one place along. Four flip-flops hold 4 bits and can convert serial data into parallel data.

Ripple counter

T flip-flops with T=1, where each one clocks the next. Q0 toggles every clock, Q1 every 2 clocks, Q2 every 4, so the outputs count in binary. N flip-flops count from 0 to 2N - 1.

Modulo-N counter

To count 0 to 9 (mod-10) with 4 flip-flops, detect the value 10 (1010) with a NAND gate and use it to reset all flip-flops. In a ripple counter each stage adds propagation delay, which limits the maximum clock speed.
