Flip-flops: SR, D, JK and T

A gate has no memory. A flip-flop stores one bit and changes only on a clock edge. Latches are level-sensitive; flip-flops are edge-triggered, which makes large circuits predictable.

SR flip-flop

Two inputs: Set and Reset. S=1 stores 1, R=1 stores 0, S=R=0 holds. S=R=1 is forbidden because the outputs conflict.

D flip-flop

Copies D to Q on each clock edge: Q+ = D. It removes the invalid state, so registers and memory use it.

JK flip-flop

Like SR, but J=K=1 toggles. Q+ = J·¬Q + ¬K·Q.

00Q

101

T flip-flop

T=1 toggles, T=0 holds: Q+ = T XOR Q. Chain T flip-flops and you get a binary counter, because each stage halves the clock frequency.

Setup and hold time

D must be stable shortly before (setup) and after (hold) the clock edge. Violating either can leave the flip-flop in an undefined state called metastability.
