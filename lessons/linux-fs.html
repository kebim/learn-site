The filesystem layout

Linux organizes everything under one root, /. Knowing where things live is the first admin skill.

PathHolds
/etcSystem configuration
/varLogs, spool, changing data
/homeUser files
/usrInstalled programs
/procLive kernel and process info

Try it

ls -l /etc | head
df -h
du -sh /var/log

Linux ले सबै कुरालाई एउटै रुट / मुनि व्यवस्थित गर्छ। कुन कुरा कहाँ हुन्छ भन्ने जान्नु नै एडमिनको पहिलो सीप हो।

पाथके हुन्छ
/etcसिस्टमको कन्फिगरेसन
/varलग र परिवर्तन भइरहने डाटा
/homeप्रयोगकर्ताका फाइलहरू
/usrस्थापना गरिएका प्रोग्रामहरू
/procकर्नेल र प्रोसेसको लाइभ जानकारी

आफैं प्रयास गर्नुहोस्

ls -l /etc | head
df -h
du -sh /var/log

df -h ले डिस्कमा कति ठाउँ बाँकी छ देखाउँछ, र du -sh ले कुनै फोल्डरले कति ठाउँ लिएको छ देखाउँछ।
