🐧 Linux System Administration

OS Core

Critical operational commands, permission math, and system triage shortcuts.

Octal Permission Shortcut

Permissions match standard numerical bits: Read (4), Write (2), Execute (1).

chmod 755 script.sh # Owner: Full (7), Group/Others: Read/Exe (5)

Triage & Process Investigation

ps aux | grep nginx      # Locate matching process IDs
lsof -i :80              # View process occupying Port 80
df -h && free -m         # Quick disk and RAM health check
journalctl -xeu ssh      # Debug failing service logs instantly

🐙 Git & GitHub Essentials

VCS

Standard tracking pipelines, data recovery, and remote state alignment.

The Standard Pipeline

git add .                  # Stage all current working directory changes
git commit -m "feat: core" # Create absolute logical point in history
git push origin main       # Sync local branch up to GitHub remote

Emergency State Manipulation

git reset --soft HEAD~1    # Undo last commit; keep your file changes
git stash && git stash pop # Save working state safely to clean working tree
git checkout -b new-branch # Create and pivot to isolated branch footprint

🛡️ Cyber Security Foundations

Defense

Structural security design principles and structural infrastructure vectors.

The CIA Triad

  • Confidentiality: Encryption at rest/flight (AES/TLS) protects data from snooping.
  • Integrity: Hashing algorithms (SHA-256) protect files against silent mutation.
  • Availability: Redundancy topologies (RAID, High Availability clusters) defend uptime.

Core Defense Mandate

"Never Trust, Always Verify."

Apply the Principle of Least Privilege (PoLP): Grant endpoints the absolute bare minimum system clearance needed to process tasks.
