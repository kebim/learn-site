🌐 Advanced Subnetting & IP Design

Networking

Breakdown of Classless Inter-Domain Routing (CIDR) logic and design math blueprints.

Core Subnetting Formulas

  • Total Subnets = 2^n (where n = borrowed host bits)
  • Usable Hosts/Subnet = (2^h) - 2 (where h = remaining host bits)

Practical Subnetting Walkthrough

Given Network Address Profile: 192.168.1.0/26

  • Subnet Mask: 255.255.255.192 (Binary: 11000000 in last octet)
  • Block Increment Size: 256 - 192 = 64 addresses per boundary.
  • Network ID: 192.168.1.0
  • Usable IP Range: 192.168.1.1 to 192.168.1.62
  • Broadcast ID: 192.168.1.63

Rebase vs Merge Strategies

Use merge to maintain true history timelines. Use rebase to create straight linear commits.

git fetch upstream          # Pull upstream project change frameworks
git checkout main
git rebase upstream/main    # Reapply local commits on top of current upstream state

Target Extraction & Inspections

git cherry-pick a1b2c3d    # Select individual commit hash from branch
git log --oneline --graph  # Render ASCII branch history relationship structure

🛡️ Cyber Security Mitigation Matrix

Security

Defense patterns mapped against the vulnerabilities in the OWASP Top 10 framework.

OWASP Risk Strategies

SQL Injection (SQLi)

Malicious queries escape input forms. Defense: Use parameterized queries and prepared statements exclusively.

Cross-Site Scripting (XSS)

Script insertion execution inside users' browsers. Defense: Context-aware output encoding and strict Content Security Policies (CSP).

Data Storage Governance

Never store raw cleartext passwords. Always run items through cryptographic functions using unique salts per entry:

Password + Unique Cryptographic Salt ➔ Argon2id / bcrypt ➔ Safe Storage Hash
