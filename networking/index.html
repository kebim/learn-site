The TCP Three-Way Handshake

1. Client ➔ Server: Send SYN [Seq = X]
2. Server ➔ Client: Send SYN-ACK [Seq = Y, Ack = X + 1]
3. Client ➔ Server: Send ACK [Ack = Y + 1]
